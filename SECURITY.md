# Security Policy

## Supported Versions

Security fixes and integrity updates are officially supported for the following releases:

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting Security Vulnerabilities

`agent-proctor` is an anticheat and code integrity gate. The integrity of our detection lattices and policy enforcement is our highest priority.

If you discover a bypass, sandbox escape, or vulnerability in `agent-proctor`, please report it responsibly:

* **Email:** security@no-hup.dev (or via GitHub Private Vulnerability Reporting)
* **What to include:**
  - A description of the bypass or attack vector
  - A minimal reproducing git patch or repository
  - Expected vs. actual verdict
* **Response Timeline:** We commit to acknowledging receipt within 24 hours and providing an initial assessment and patch plan within 72 hours.

Please do not report security vulnerabilities through public GitHub issues.
